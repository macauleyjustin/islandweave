# Known Limitations

1. **Current Release Scope (`v1.0.0`):** All core daemon, CLI (`island`), Desktop Control Center (`island-desktop`), Navigator (`island-navigator`), scenario simulator (`island-simulator`), routing (`IWP-ROUTE`), anti-entropy sync (`IWP-SYNC`), discovery (`IWP-DISCOVER` / `IWP-BEACON`), DTN/Courier, IWMP Mail, IWBN Bulletins, Tor SOCKS5, Federation, Shared Libraries, and IWST Contact Simulator subsystems are implemented, live-tested on `darwin/arm64`, and packaged for cross-platform distribution.
2. **Hardware-Gated Wireless & Satellite Transports:** Wi-Fi hotspot creation (SoftAP), Bluetooth Low Energy (BLE) GATT/advertising, Wi-Fi Aware/Direct, and live RF satellite transmissions require OS-specific privileged wireless drivers/entitlements or licensed ground-station RF hardware.
3. **Key Storage:** Private keys are persisted locally on disk (`<data-dir>/keys/node.json`) with POSIX `0600` file permissions rather than OS-native hardware keychains (Keychain Services / libsecret / DPAPI).
4. **Underlying Stream Transport:** `IWP-LINK/1` operates over TCP (direct LAN/WAN or Tor SOCKS5); QUIC framing is not yet added as a secondary stream adapter.
5. **Cross-Platform Runtime Verification:** Runtime tests and live multi-binary smoke tests were executed on `darwin/arm64`; Linux (`amd64`/`arm64`) and Windows (`amd64`) release binaries cross-compile cleanly with pure Go (`CGO` not required) and await target-OS runtime verification.
